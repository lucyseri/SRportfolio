Skills

1. Introduction

HTML

웹 표준과 웹 접근성을 준수하며 HTML5에서 권장하는 마크업 방식에 따라 퍼블리싱 합니다. 시맨틱 태그로 레이아웃을 설계하고, 이미지 스프라이트 및 IR 기법을 사용하는 등 효율성과 접근성을 고려한 마크업을 구현합니다.
마크업 과정 중에는 W3C CSS Validation, W3C Markup Validation 검사를 통해 웹 표준 준수 여부를 점검합니다.
체계적인 HTML 마크업을 위해 마크업 이전의 UXUI 과정에서부터 스타일 가이드, 와이어 프레임, 스토리보드 등을 사전에 작성하고 이에 따라 HTML 구조를 설계하고 퍼블리싱 합니다.

CSS & SCSS

HTML과 스타일을 분리하여 작성하고, 공통 컴포넌트와 UI 요소를 재사용 할 수 있도록 체계적인 자료 구조를 구축합니다. 또한, 크로스 브라우징을 고려해 일관된 퍼블리싱을 합니다. 특히, CSS3에서 지원하는 transition, transform, animation, grid 등을 적극적으로 사용해 동적인 UI를 구현합니다.
이와 동시에 벤더 프리픽스와 브라우저 지원 여부를 고려하여 안정적인 스타일 또한 구현합니다. 미디어 쿼리를 통한 반응형 웹 작업 또한 프로젝트 특성에 따라 float, flexbox, grid layout 등을 적절하게 활용합니다.
재사용성과 생산성을 위해 SCSS를 활용합니다. 믹스인, 중첩, 반복문, 조건문 등을 사용하여 유지 보수에 용이하도록 합니다.

Javascript & JQuery

제이쿼리의 다양한 메서드와 애니메이션 기능을 활용해 외부 플러그인 없이 내비게이션, 아코디언, 배너 슬라이더 등의 인터랙티브 웹 퍼블리싱을 합니다. 특히, load 메서드를 활용해 헤더와 푸터 등의 공통 요소를 효율적으로 구현합니다.
다양한 조건문과 반복문, 배열 및 메서드를 활용한 바닐라 자바스크립트로 내비게이션, 탭 메뉴, 스크롤 애니메이션, 모달 팝업 등 인터랙티브한 웹 사이트를 제작합니다. 또한, 객체 지향 프로그래밍과 모듈화를 적용해 효율적인 코드를 작성합니다.
더불어, slick.js, masonry.js featherlight.js 등의 라이브러리와 플러그인을 활용할 수 있습니다.

Photoshop / Illustrator / Figma

아이콘, 일러스트 제작에는 일러스트레이터를 주로 사용하며, 상품 상세페이지와 배너, 웹 콘텐츠 제작을 위한 이미지 편집과 합성에는 포토샵을 주로 활용합니다.
피그마의 컴포넌트 및 오토 레이아웃 기능을 활용해 와이어 프레임과 UXUI 디자인 시안 등을 제작합니다. 피그마의 기능 중 피그 잼을 활용하여 정보 구조 설계 워크플로우 등을 작성하는 등 협업 작업을 수행할 수 있습니다.

visual studio code

텍스트 에디터로는 비주얼 스튜디오 코드를 사용합니다. 다양한 확장 프로그램을 활용하여 보다 생산적으로 코드를 작성합니다.
특히, 효율적인 프로젝트 관리와 유지 보수를 위해 SCSS 컴파일러 및 git 연동 기능을 활용합니다.

Git hub

Git과 gti hub를 활용해 프로젝트 버전을 관리합니다. Commit, push, pull, merge 등의 기본적인 과정을 이해하고 활용하여 협업 과정에서 발생하는 충돌을 해결하며 다양한 환경에 구애받지 않고 작업할 수 있습니다.
